기기 내 게임 정보는 기본적으로 기기에 저장됩니다. 순위에 필요한 일부 클리어·프로필 정보만 Firebase 서버로 전송됩니다.

수집하지 않는 정보: 앱은 이메일 주소, 전화번호, 연락처, 사진, 정밀 위치, 결제 수단 정보를 직접 요구하거나 저장하지 않습니다. 현재 빌드에는 인앱 결제 기능이 없습니다.

2. 정보 처리 방법과 선택권

  • 순위 서버를 사용할 때 Firebase 익명 계정이 자동 생성됩니다. 별도의 이메일·전화번호 로그인은 없습니다.
  • 사용자가 정한 별명#번호, 선택한 고양이, 점수와 순위는 다른 순위 이용자에게 공개될 수 있습니다. 별명에 실명이나 연락처 등 개인정보를 입력하지 마세요.
  • 광고 SDK는 앱 실행과 광고 이용 과정에서 광고·기기 정보를 자동으로 처리할 수 있습니다.
  • 진동 설정은 앱에서 변경할 수 있고, 광고 ID는 Android 기기 설정에서 재설정하거나 삭제할 수 있습니다.

4. 외부 서비스와 국외 처리

앱은 아래 Google 서비스를 이용합니다. 정보는 앱 기능을 사용하는 시점에 암호화된 네트워크로 전송되며, Google의 대한민국 외 데이터센터에서도 처리될 수 있습니다.

  • Firebase Authentication: 익명 사용자 인증 및 사용자 ID 관리
  • Cloud Functions / Cloud Firestore: 프로필, 클리어 검증, 공개 ID 예약, 주간·누적 순위 처리
  • Google Mobile Ads: 배너·전면·보상형 광고 게재, 측정, 분석과 사기 방지

처리 사업자: Google LLC 및 그 계열사 · 관련 정책: Google 개인정보처리방침, Firebase 개인정보 안내, Google 광고 정책

5. 보관 기간과 보안

  • 익명 계정, 공개 프로필과 순위 데이터는 서비스 제공 기간 또는 계정 삭제 시까지 보관합니다.
  • 삭제 요청은 본인 확인 후 원칙적으로 30일 이내 처리합니다. 법률 준수, 보안 또는 사기 방지를 위해 일부 정보를 보관해야 하는 경우 그 사유와 기간을 안내합니다.
  • 기기 내 데이터는 앱 데이터 삭제 또는 앱 제거로 삭제할 수 있습니다.
  • 네트워크 통신은 HTTPS/TLS로 암호화하며, Firestore 직접 접근은 차단하고 서버 함수가 필요한 데이터만 처리합니다.
  • 광고·진단 정보의 보관 기간은 Google의 서비스 정책과 사용자 설정을 따릅니다.

6. 이용자 권리

이용자는 자신의 정보에 대한 열람, 정정, 삭제, 처리 제한 또는 동의 철회를 요청할 수 있습니다. 별명과 선택 고양이는 앱의 프로필 화면에서 변경할 수 있으며, 서버 계정과 연결 데이터 삭제는 아래 절차를 이용합니다.

7. 계정 및 데이터 삭제 요청

앱을 삭제했거나 실행할 수 없는 경우에도 이메일로 Firebase 익명 계정과 연결 데이터 삭제를 요청할 수 있습니다.

  1. 앱의 프로필 화면에 표시된 별명#번호를 확인합니다.
  2. 아래 버튼으로 삭제 요청 이메일을 보내고 별명#번호를 적습니다.
  3. 운영자가 계정 소유 확인을 위한 추가 절차를 안내할 수 있습니다.
  4. 확인 후 Firebase 익명 계정, 공개 ID 예약, 프로필, 클리어 제출 기록과 순위 연결 데이터를 원칙적으로 30일 이내 삭제합니다.

앱을 제거하면 기기에만 저장된 퍼즐 진행과 설정도 삭제됩니다. 서버 삭제 전에는 앱 제거만으로 서버 데이터가 삭제되지 않습니다.

8. 아동의 개인정보

9. 방침 변경

법령, 앱 기능 또는 외부 서비스가 변경되면 본 방침을 수정할 수 있습니다. 중요한 변경 사항은 앱 또는 이 페이지를 통해 안내하고 시행일을 갱신합니다.
